# Data Structures and Algorithms in C++

## 📌 Description

This repository contains my implementations of fundamental data structures and algorithms using C++. The project focuses on understanding core computer science concepts and improving problem-solving skills.

## 📚 Topics Covered

### Data Structures

* **Stack**

  * LIFO (Last In, First Out) operations
  * Push, Pop, and Peek operations

* **Queue**

  * FIFO (First In, First Out) operations
  * Enqueue and Dequeue operations

* **Linked List**

  * Singly Linked List
  * Doubly Linked List
  * Node-based data management

* **Trees**

  * Basic tree structures
  * Tree traversal techniques

* **Graphs**

  * Graph representation
  * Graph traversal algorithms

### Algorithms

* Sorting Algorithms

  * Bubble Sort
  * Selection Sort
  * Insertion Sort
  * Other sorting techniques

## 🛠️ Technologies Used

* C++
* Object-Oriented Programming (OOP)
* Standard Template Library (STL)
